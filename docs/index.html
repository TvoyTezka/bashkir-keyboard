Перед первым запуском

В каких приложениях работает замена?

Обработка клавиатуры глобальная, но замена зависит от доступности текстового поля через Windows UI Automation. Если положение курсора проверить нельзя, приложение оставляет обычный ввод. Совместимость всех версий редакторов не гарантируется.

Почему Windows может показать предупреждение?

Сборка пока не подписана цифровой подписью. Windows может предупредить о неизвестном издателе. Открытый код позволяет изучить приложение и собрать его самостоятельно, но не заменяет цифровую подпись.

Что происходит, если нажать другую клавишу?

Ожидающая замена отменяется. Щелчок, смена окна или раскладки тоже отменяют удержание. Это помогает избежать удаления другой буквы.

Можно ли оставить английскую раскладку?

На английской раскладке замены отключены. Для башкирского ввода переключитесь на обычную русскую раскладку.

Приложение читает и сохраняет мой текст?

Для проверки замены оно кратковременно сравнивает один символ перед курсором в доступном непарольном поле. Этот текст не сохраняется и не отправляется. Полное описание доступно в документе о приватности.
