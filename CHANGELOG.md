# Changelog

## 1.0.0

- Instant regular typing and hold-to-replace for nine Bashkir letters.
- Focus, layout and caret checks; cancel replacements after unrelated input.
- Shift and Caps Lock support; system shortcuts take priority.
- Configurable hold delay and mappings, system tray and Windows autostart.
- Custom icon, Start menu shortcut and portable Windows x64 release.
- Automated hold-logic and WinAPI keyboard translation checks.

Replacement depends on Windows UI Automation support in the target editor. The release is not digitally signed yet. See README for compatibility notes.

# Изменения

## 1.0.0

- Мгновенный обычный ввод и замена при удержании для девяти башкирских букв.
- Проверка фокуса, раскладки и положения курсора; отмена при постороннем вводе.
- Поддержка Shift/Caps Lock и приоритет системных горячих клавиш.
- Настройки задержки и соответствий, системный трей, автозапуск.
- Собственная иконка, ярлык в меню «Пуск», переносимая Windows x64-сборка.
- Автоматические проверки логики удержания и преобразования клавиш через WinAPI.

Замена зависит от поддержки UI Automation целевым редактором. Готовая сборка не подписана цифровой подписью. Подробные ограничения перечислены в README.
